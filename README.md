# The Backup Basics Handbook

*Never lose your stuff again — explained like a friend would.*

This is a plain-English manual about backups: what actually needs backing up,
how the 3-2-1 rule works without any jargon, simple external-drive routines,
honest trade-offs between free cloud and local storage, phone photo backups,
file formats that will still open in ten years, restore drills, and what to do
in the first hour after a crash.

It also includes:

- A **printable backup-plan worksheet** you can fill out and stick on the fridge.
- A **glossary** where every term is explained in one friendly sentence.
- **Recipes** — short, step-by-step backups tasks with a "check your work"
  section, so you know it worked.

The tone is warm, not condescending. There's no shame in starting at zero —
this whole book assumes you did.

## How to read it

- Online: open `site/index.html` in any browser, or run the build (below).
- Print: `docs/worksheet.md` builds to a print-friendly page for the fridge door.

## Build the site

No dependencies. Just Python 3:

```sh
./build.sh
```

or, equivalently:

```sh
python3 build.py
```

This reads the Markdown in `docs/` and writes a static site to `site/`.
Open `site/index.html` — everything works offline, no internet needed.

## Run the checks

```sh
./test.sh
```

This rebuilds the site, checks that every page was generated, that internal
links resolve, that the LICENSE/README credits are intact, and walks the
restore-drill recipe to prove the commands in it actually work.

## Repository layout

```
docs/        the handbook, chapter by chapter (Markdown)
docs/recipes/ short step-by-step tasks with checks
site/        the built static site (regenerated by build.sh)
assets/      one stylesheet, used by the build
build.py     Markdown → HTML converter (Python standard library only)
build.sh     convenience wrapper around build.py
test.sh      build + structure + link + recipe checks
```
