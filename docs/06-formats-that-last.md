# Formats That Last: Copying Documents So They Open in Ten Years

Backups protect files from *disappearing*. This chapter protects them from
something sneakier: the file surviving fine, but nothing on Earth opening
it. Formats rot slower than drives, but they do rot — old apps, old
versions, old locks. Here's the ten-year-survival kit, and most of it is
about *which* file types you keep and *how* you name and copy them.

## The friendly rule for formats

**Keep the "speakable" versions — files that many different apps can open —
and keep the fancy version alongside them, behind them, when you have one.**

Formats that are easy to open basically forever:

| Kind of thing | Keep this | Why it lasts |
| --- | --- | --- |
| Documents meant to be *read* (leases, agreements, receipts, letters) | **PDF** (or PDF/A when offered) | Every device since 1993 opens it; looks the same everywhere |
| Plain writing, notes, journal, the novel's outline | **.txt or .md** (plain text / Markdown) | Text is text; apps come and go, letters stay letters |
| Essays/resumes you'll *edit* later | Your editor's format **plus** a PDF copy | The PDF is the ten-year copy; the original is the editing copy |
| Photos and scans | **JPEG/JPG** and **PNG** | Universal; JPEG for camera photos, PNG for graphics/screenshots |
| Spreadsheets that only need to be looked at | **CSV** alongside the spreadsheet | CSV is plain text; any tool reads it in 2050 |
| Tax/money records | **PDF** of the return + CSV export of the data | One is for reading, one survives the software apocalypse |

Formats that rot faster (keep them, but never as the *only* copy):

- Anything saved by abandoned software — old graphic-designer files,
  ancient bookkeeping-app files, the label-maker's data.
- Formats unique to one company's app, where the app itself needed to render
  them correctly.
- Anything with **DRM** (digital locks) — the store can take the key back.
  That's not a backup; that's a lease.

## The two-copy trick for anything you must keep *editable*

Keep both, always, with clear names:

```
resume-2026.docx          ← the living, editing copy
resume-2026.pdf           ← the will-still-open-in-2036 copy
```

Same rule for scanned paperwork: if your scanner/phone app produced a
PDF, lovely — but if it produced some app-private format, export to PDF
before it goes in the archive.

## Naming: dates that sort themselves

Ten years from now, "Scanned Document (3).pdf" tells you nothing. The
friend-style naming pattern:

```
YYYY-MM-DD-what-it-is.pdf
2026-10-25-apartment-lease.pdf
2025-04-02-car-insurance-policy.pdf
```

This sorts perfectly so the file openers, file finders, and *you in ten
years* all agree what happened when. Also — your future self will be
searching for the words, so put the words in the name: "lease," "insurance,"
"taxes." Never "Doc1," never "final_FINAL_v2(real)".

## Structure: copy folders, not loose files

A file often doesn't make sense alone (the spreadsheet is fine, but the
spreadsheet + the PDF its cells point at + the "read me" note explaining
the columns = the *real* document). When you back up paperwork, copy the
whole folder. Follow this shape if it helps:

```
Papers/
  2026/
    2026-10-25-lease.pdf
    2026-11-01-insurance.pdf
  taxes/
    2025/
      ...
```

Year folders, date-named files inside. Nothing clever. Your future self,
or a relative helping you in an emergency, can walk in and read it with
zero tools.

## The once-a-year open test

Remember the chapter promise: "they open in ten years." Here's the test —
once a year (bakery-cake day? Valentine's? pick an easy-to-remember date):

1. Open your archive — the drive, the cloud folder both.
2. Open three files at random: a PDF, the oldest file there, and one
   spreadsheet/CSV.
3. If all three open on your *current* computer: archive healthy.
4. Also check: nothing you can't read the name of. Fix weird names while
   you're there.

If something doesn't open: that's *exactly* why you kept the plain
version next to the fancy one (the PDF beside the editor file). Open the
plain version, mark the fancy one as retired, and feel pleasantly smug.

## Two more ten-year traps

- **Password-protected / locked PDFs**: fine to have, but *record where the
  password lives* — with the file's location noted on your worksheet and in
  your password manager. A perfect backup you can't unlock is a locked box
  in a burned house. (Password goes in the manager, never in the filename.)
- **Optical discs and "special" media**: CDs/DVDs from 2008 and camera-SIM
  cards and devices with proprietary connectors should all be **migrated**
  — copied to modern drives/files — during one of your yearly reviews.
  Modern formats live on modern media.

## Do this today

1. Pick your top-five most important documents.
2. Make sure each has a PDF (or CSV/txt) version — export if not. Name it
   with the date pattern.
3. Drop them in the treasure folder that your weekly recipe already backs
   up. That's paperwork insurance for the price of ten minutes.
