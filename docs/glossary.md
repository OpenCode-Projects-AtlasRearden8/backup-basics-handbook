# Glossary: Every Word, One Friendly Sentence

Plain-English definitions. No defense of jargon our field is quietly proud
of — just the words you need, said like a person.

**Backup** — a second copy of a file, kept somewhere that isn't the
original's home, so one mishap can't delete both.

**Cloud** — somebody else's computer that you reach over the internet; your
files get copied up to it, usually automatically.

**Copy (the real kind)** — a file that exists independently, so deleting or
breaking one leaves the other untouched.

**CSV** — a spreadsheet saved as plain text; less pretty, opens forever.

**DRM (digital rights management)** — a digital lock a store puts on
media; it isn't a backup, it's a lease, and the landlord can change the
terms.

**External drive** — a storage drive in its own little box that plugs into
your computer with a cable; the unsung hero of this book.

**File format** — which "language" a file speaks (PDF, JPEG, .docx); some
languages are spoken by everything forever (PDF), some only by one retired
app.

**Format (the verb)** — to prepare a drive so a computer can use it; also
the word that warns you it's emptying the drive, so read the pop-up.

**HDD** — a hard drive with spinning plates inside; cheap, big, slightly
fragile, perfectly fine for backups.

**Incremental backup** — copying only what changed since last time, so
week 47 takes seconds instead of an hour.

**Mirror / sync** — keeping a folder identical in two places; convenient,
but deletions travel too, so it's not a backup history.

**Offsite** — a copy stored somewhere else than your main home (a relative,
work drawer, or the cloud); survives the in-the-room disasters.

**PDF / PDF/A** — the "it looks the same everywhere and opens forever"
document format; PDF/A is its archive-flavored, built-to-last version.

**Plain text (.txt / .md)** — files that are just letters; the cockroaches
of the file world — outlive everything.

**PNG** — a universal image format, best for screenshots and graphics.

**RAID** — multiple drives glued together to keep working when one dies;
great for uptime, **not** a backup, because deletion and fire still wipe
the glued set.

**Restore** — the act of getting a file back from a backup; the reason
backups exist, and the part everyone forgets to practice.

**Restore drill** — deliberately bob-for-a-file: delete one, get it back,
prove it opens; a fire drill for data.

**SSD** — a drive with no moving parts; faster and tougher than HDD, costs
more per space.

**Trash / Recycle Bin** — the device's own recent-deletions holding cell,
usually ~30 days — your first recovery stop after a mistake.

**Version history** — a cloud folder's memory of previous versions of a
file; priceless after an accidental overwrite.
