# Recipes: Small Tasks, Done and Checked

Each recipe below is a short task with its steps, a way to **check your
work**, and what to do if something's off. They're written so the checkbox
temporarily lives in your brain, then gets checked off on paper for good.

| Recipe | You'll spend | What you end up with |
| --- | --- | --- |
| [Recipe 1 — Make Your First Real Copy](recipe-01-first-copy.html) | 10–20 min | Treasure folder on an external drive |
| [Recipe 2 — Prove You Can Restore](recipe-02-restore-drill.html) | 15 min | A logged restore drill and actual confidence |
| [Recipe 3 — Turn On Automatic Backups](recipe-03-auto-backup.html) | 10 min | Your OS guarding you while you sleep |
| [Recipe 4 — Put a Folder in the Cloud](recipe-04-cloud-folder.html) | 10 min | Copy #3 living offsite, hands-free |
| [Recipe 5 — The Yearly Archive Check](recipe-05-yearly-archive-check.html) | 30 min, yearly | Files verified openable, names fixed, formats migrated |

Honesty note, before you read further: the shell commands in recipes 1, 2
and 5 have been run end to end in a test shell (recipe 2 includes a checksum
comparison, but you don't have to use that part); the click-by-click GUI
recipes 3 and 4 follow each operating system's official steps, but menu
names drift as versions change — if a menu looks different, trust the
surrounding words ("backup," "sync," "turn on") over the exact wording here.
