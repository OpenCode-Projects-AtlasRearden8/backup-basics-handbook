# The Backup-Plan Worksheet

Print this page (Ctrl/Cmd-P — the layout is print-ready), fill it out with
a real pen, and stick it somewhere you'll see it: side of the fridge, inside
a cabinet, back of a planner. When something goes wrong, this page is the
calm, pre-loaded answer sheet.

## Part 3 — My rhythm

- [ ] Weekly: plug in drive A, run copy recipe, update the masking-tape date
- [ ] Monthly (or auto): photos checked — phone backup says complete
- [ ] Quarterly: restore drill — pick one file, delete, restore, verify, log below
- [ ] Twice a year: cloud drill — log in from *another device*, download one file
- [ ] Yearly: open-test archive (one PDF, one old file, one spreadsheet/CSV); migrate anything weird
- [ ] Yearly: rotate drive B between a relative's place and your desk drawer

## Part 6 — After-a-crash cheat line

*If the computer bursts into its own sad drama, my first three steps are:*

1. Breathe. Touch nothing that offers to "repair" or "reset."
2. List what's *actually* lost using Part 1; circle anything with no copy.
3. Check cloud from another device + plug drive into a *healthy* machine.
